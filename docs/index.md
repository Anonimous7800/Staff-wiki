## 🚀 Inicio Rápido en 3 Pasos

```bash
# 1. Coloca staff-5.0.4.jar en la carpeta /plugins de tu servidor
# 2. Inicia o reinicia tu servidor de Minecraft
# 3. Asigna el permiso staff.mode a tu rango y ejecuta /staff en el juego
```

::: tip Soporte Moderno
Esta versión cuenta con soporte completo y adaptadores nativos para **Paper 26.3**, **Java 25**, y las últimas versiones de PaperMC y Spigot.
:::
